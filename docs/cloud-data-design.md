# 拾光云同步设计

用户需要同一账号跨设备读取记录，并在未来网页改版和功能增加时保留记录。已有 GitHub Pages 网址和浏览器旧记录都保留。

网页继续通过 GitHub Pages 部署。Supabase Auth 提供邮箱密码登录和恢复密码；PostgreSQL 保存每个账号独立的手账文档。表由数据库 RLS 限制 auth.uid() 等于 user_id；公开网页只使用 publishable key。RPC 使用 security invoker，不接受可伪造的 user_id 参数。

本地旧键 shiguang-journal-v1 不改动。云端副本和待上传内容使用项目及用户 ID 隔离的缓存键。首次登录先读取云端，用户再点击导入本机旧记录，导入只合并、不替换云端全部数据。

同步使用版本检查及三方合并（上次云端副本、本机内容、最新云端内容）。不同记录并行修改合并；同一记录修改冲突和删除/修改冲突需用户选择。上传前保存待上传内容，网络失败保留缓存，刷新后仍可重试。上传成功才显示已同步。账号切换停止前一账号同步并阻止响应回写界面。

页面前台每 15 秒拉取一次，恢复联网及切回页面立即重试。JSON 导入导出和人生清单长图仍可使用。草稿和界面主题为当前设备偏好；感悟和人生事项跨设备同步。

数据库保留最近 50 次修改前的文档快照，可下载恢复。网页部署不重建数据库；后续数据库调整通过新增 SQL 迁移保留原数据，保留数据格式版本和原始无法读取的缓存。

验证包括：旧功能回归、离线新增重载恢复、删除不复活、并发修改版本竞争、同条冲突显式处理、上传中继续编辑、账号隔离、退出账号忽略异步结果、存储失败及匿名/跨账号数据库权限。接入真实项目后需要运行真实登录读写和数据库权限测试；未完成连接前不能宣布云同步可用。

当前外部依赖：用户创建 Free 项目并提供 Project URL 与 publishable key，完成 Supabase 管理连接以执行建库 SQL。Free 项目可能因长期低活动暂停；不自动开通付费。
